## The whole stack, one pair of hands

**Interface.** Accessible, responsive UIs where the details are right: semantics, states, motion that has a reason.

**Server.** Clean REST APIs, authentication, validation, and the unglamorous parts that keep an app alive in production.

**Data.** Schemas designed around the questions the product will ask, not just the ones it asks today.

## How I work

- **Ship in small steps.** Every commit does one thing and says what it did.
- **Type it.** TypeScript end to end, so the compiler catches mistakes before users do.
- **Design the contract first.** The API shape and the data model come before the screens that depend on them.
- **Accessible by default.** If it can't be used with a keyboard, it isn't finished.
- **Leave it readable.** The next person to open the file might be me in six months.
